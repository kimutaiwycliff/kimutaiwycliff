### Wycliff Kimutai

Geospatial software engineer in Nairobi. I trained as a surveyor (BSc Geomatics Engineering, JKUAT), did an MSc in Data Analytics, and now build the systems that sit between spatial data and the people who need it.

Since 2022 I have worked on **Ardhisasa**, Kenya's national land information system: a QGIS plugin used by government surveyors to check and certify parcel jobs, cadastre data validation, and the GeoServer/PostGIS services behind the web and desktop clients.

Outside work I mostly build open geospatial infrastructure and climate/disaster-risk tools:

|---|---|
